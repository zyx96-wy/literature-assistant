## G.1 发现与入库

**用户动作**：
用户在 arXiv 看到一篇论文，把链接发给助手。

**系统响应**：
- `add --url` 抓取标题 / 作者 / 日期 / 摘要 → 下载 PDF 抽正文入库
- 走三重去重（MD5 / 标题 / 正文相似）
- 自动生成阅读页 + 速读页
- 刷新工作台首页

**涉及模块**：文献入库、工作台与页面

**产出**：文献条目 + 阅读页 + 速读页 + 工作台更新

**断点检查**：
- 重复入库 → `DUPLICATE_FILE` / `DUPLICATE_TITLE`
- 疑似重复 → `SIMILAR_SUSPECT`，问用户「仍要入库 / 取消」

---

## G.2 速读

**用户动作**：
用户不想读全文，先看速读页了解主旨、方法、结论。

**系统响应**：
- 展示 11 字段速读卡
- 每个字段带来源 chip，可点回原文 `#pN`
- 金句卡逐字摘录
- 未提及字段灰显

**涉及模块**：文献速读、文献入库、工作台与页面

**产出**：速读卡 + 来源锚点

**断点检查**：
- 深解析未做 → 提示「是否深解析这篇？」
- 字段未提及 → 如实标注，不编造

---

## G.3 精读

**用户动作**：
用户打开阅读页，开始逐段精读。

**系统响应**：
- 双栏布局：左侧目录 + 正文卡片，右侧笔记面板
- 每张卡片有全篇唯一段落号 ¶N
- 英文文献译文内联显示
- 自动记录阅读进度

**涉及模块**：工作台与页面、阅读时间记忆、翻译

**产出**：阅读进度记录 + 译文（如有）

**断点检查**：
- 桥接未连接 → 黄条「⚠️ 桥接未连接」+ 启动命令
- 阅读进度未同步 → 导出 `reading_log_import.json` 兜底

---

## G.4 划线与笔记

**用户动作**：
用户读到一段有感触，选中一句话划线，然后写笔记。

**系统响应**：
- 选中句子 → 浮动「划线」按钮 → 点即高亮
- 点「📝 笔记」→ 面板弹精简表单
- 原文片段自动抓取存档
- 完成后面板出现条目，带时间「N月N日 HH:MM · 第N段」
- 卡片底部显示摘要「📝 我的笔记：…」

**涉及模块**：笔记与划线、工作台与页面

**产出**：划线 + 笔记条目 + 快照

**断点检查**：
- 该段已有笔记 → 问「要更新还是新建？」
- 更新 → 版本链追加；新建 → 关联笔记

---

## G.5 笔记演化

**用户动作**：
一个月后，用户重读这段，有了新见解，点「编辑」。

**系统响应**：
- 弹出选择：「更新这条笔记」或「新建一条笔记」
- 更新 → 追加新版本，旧版本保留
- 新建 → 原笔记保留，新笔记关联同一段
- 面板可展开「演化过程」，看到 v1 → v2 → v3

**涉及模块**：笔记与划线

**产出**：版本链 + 关联笔记

**断点检查**：
- 删单版本 → 二次确认，标记 `deleted: true`，可恢复
- 删整条笔记 → 二次确认，提示版本数
- 原文被软删 / purge → 笔记保留，标注「原文已删除」

---

## G.6 问答

**用户动作**：
用户想问「这篇论文的方法和 XXX 有什么区别？」

**系统响应**：
- 先在知识库里找相似问答
- 命中 → 标「📌 来自你的知识库」直接返回
- 未命中 → `ask` 检索文献 → 给带来源的答案
- 自动存历史 + 刷新工作台
- 来源卡可点击跳原文并高亮

**涉及模块**：检索问答、问答助手、知识库页、工作台与页面

**产出**：带来源的答案 + 问答历史 + 来源卡

**断点检查**：
- 文献无依据 → 明说「没找到相关依据」，不编造
- 用户收藏 → 写入 `qa_knowledge.json`
- 删已收藏问答 → 问「是否连带删知识条目」

---

## G.7 限定范围问答

**用户动作**：
用户想只对比《A》《B》两篇，把文献卡片拖进问答框。

**系统响应**：
- 自动填入 `【lit_xxx】` 标记
- 标记等价于 `--docs`，限定检索范围
- 重复拖同一篇去重
- 答案只在限定范围内检索

**涉及模块**：文献拖拽、检索问答、问答助手

**产出**：限定范围的答案

**断点检查**：
- 引用找不到 / 已软删 / 已彻底删除 → 如实报 `BAD_DOCS`
- 拖拽重复 → 只保留一个标记

---

## G.8 对比分析

**用户动作**：
用户说「对比这几篇，看方法差异」。

**系统响应**：
- `intent` 亮牌：`intent=compare` + 候选清单 + `needs_confirmation=True`
- 展示清单给用户确认
- 确认后 `comparison_table` 生成 HTML 表格
- 对话内给要点概述

**涉及模块**：对比分析、文献拖拽、工作台与页面

**产出**：对比 HTML 表格 + 要点概述

**断点检查**：
- 候选 <2 篇 → `missing` 提示补充
- 别名歧义 → 亮牌让用户选，不任选
- 模糊句 → `ambiguous`，对比 / 综述两种可能都亮出来

---

## G.9 综述生成

**用户动作**：
用户说「帮我写这个主题的综述」。

**系统响应**：
- `intent` 亮牌：`intent=review` + 候选全库清单 + `needs_confirmation=True`
- 确认覆盖范围
- `review --topic` 检索 + 对照历史笔记 + 溯源
- 每个论点带 `lit_xxx ¶N [章节]`
- 对照历史笔记标「我当时的看法」
- 生成后 `status=awaiting_review` 停等审阅
- 用户确认后生成 HTML / MD，带 `[n]` 引用

**涉及模块**：综述生成、笔记与划线、检索问答、工作台与页面

**产出**：带引用的综述 HTML / MD

**断点检查**：
- 范围可预期：亮牌范围 == 实际检索范围，绝不自扩库
- 「我当时的看法」真实命中，不编造
- 每论点溯源齐全
- 生成后停等，不自动继续

---

## G.10 复用与复习

**用户动作**：
用户想问「我之前对 XX 有什么看法？」或「我最近在读什么？」

**系统响应**：
- 笔记驱动问答：检索笔记生成回答，标「来自你的笔记」
- 阅读时间记忆：`reading --recent 5` 列最近阅读会话
- 继续阅读：工作台左栏最近 3 篇，点击直达
- 遗忘曲线：读完 N 天后建议复习（P1）

**涉及模块**：笔记与划线、阅读时间记忆、检索问答

**产出**：笔记驱动回答 + 阅读进度 + 复习建议

**断点检查**：
- 无阅读记录 → 明说「还没有阅读记录」，不编造
- 笔记无相关内容 → 明说「无相关笔记」，不编造
- 停留 <10 秒 → 不算阅读，不占「继续阅读」位

---

## G.11 标签管理

**用户动作**：
用户给《XXX》打标签「方法」「实验」，并想在标签里找文献。

**系统响应**：
- `tag --add` 打标签 → 回「已更新，当前标签：…」
- 工作台按标签筛选
- 全局改名 / 删除时先报影响清单，确认后执行

**涉及模块**：标签管理、工作台与页面

**产出**：标签更新 + 筛选结果

**断点检查**：
- 全局改名 / 删除未确认 → 不执行
- 标签冲突 → 提示

---

## G.12 阅读状态管理

**用户动作**：
用户把一篇读完的文献标为「已读」，把一篇暂存的标为「未读」。

**系统响应**：
- 写 `meta.status`
- 工作台按已读 / 未读筛选
- 与自动阅读记录独立

**涉及模块**：阅读状态、工作台与页面

**产出**：状态更新

**断点检查**：
- 手动标记不受自动记录影响
- 无记录 → 不显示「上次读到」

---

## G.13 删除与恢复

**用户动作**：
用户删掉一篇不想再看的文献，之后又想找回来。

**系统响应**：
- `delete` 软删除，打 `deleted:true`，笔记 / 问答 / 划线全保留
- 文献从 list / search / ask / 工作台排除
- 问答历史来源卡显示「原文已删除」，链接不可点击
- `restore` 恢复，文献及全部关联数据回来
- `purge` 彻底删除：先打印影响清单，二次确认后执行

**涉及模块**：数据管理与删除、工作台与页面

**产出**：软删 / 恢复 / 彻底删除

**断点检查**：
- purge 未确认 → 不执行
- purge 被系统限制 → 隔离到 `data/.purged/`，报 `quarantined_files`
- 真失败 → 返回 `purge_incomplete:true` + `failed_files`，不静默

---

## G.14 笔记总览与导出

**用户动作**：
用户打开笔记总览，筛选本周笔记，导出 Markdown。

**系统响应**：
- 按文献分组展示
- 按时间 / 文献 / 只看笔记筛选
- 点「↪ 跳到原文」跳回并高亮
- 就地编辑 / 删除
- 导出 Markdown，带版本链

**涉及模块**：笔记与划线、笔记总览页、工作台与页面

**产出**：笔记总览 HTML + 导出 md

**断点检查**：
- file:// 下编辑 / 删除被拦截，黄条提示
- 桥接在线时实时拉取快照

---

## G.15 知识库管理

**用户动作**：
用户收藏了几条问答，想集中查看、编辑、导出。

**系统响应**：
- 打开知识库页 `knowledge.html`
- 按时间倒序展示条目
- 按文献 / 标签 / 时间筛选
- 编辑答案、补充备注
- 删除条目，二次确认
- 导出 Markdown / CSV
- 下次相似问题 `qa --match` 命中 → 优先返回

**涉及模块**：知识库页、问答助手、检索问答、工作台与页面

**产出**：收藏条目管理 + 导出文件

**断点检查**：
- 空状态 → 提示「去问答里收藏」
- 桥接未连接 → 黄条提示，编辑 / 删除被拦截

---

## G.16 复现准备

**用户动作**：
用户想复现一篇论文，问「这篇复现需要什么」。

**系统响应**：
- 从深解析 11 字段抽复现清单
- 每步带 `lit_xxx ¶N [章节]` 来源锚点
- 论文未提及的如实标注「论文中未提及」
- 缺口汇总列出所有未提及项
- 清单可导出 Markdown / CSV

**涉及模块**：复现模式、文献速读、工作台与页面

**产出**：复现步骤清单 + 缺口汇总

**断点检查**：
- 深解析未做 → 提示「是否先深解析」
- 论文未提及 → 如实标注，不编造
- 不承诺可复现

---

## G.17 组会准备

**用户动作**：
用户要组会讲一篇论文，想知道模型是什么、可能被问什么。

**系统响应**：
- 从文献抽模型名 / 术语，形成卡片
- 模型卡片带出处，文献没解释的如实说「未找到」
- 查询优先级：文献内 > 内置库 > 用户导入库
- 基于文献内容生成「可能被问到的问题」
- 整理讲稿素材

**涉及模块**：模型卡片、外部知识库、翻译、工作台与页面

**产出**：模型卡片 + 术语卡片 + 提问预演

**断点检查**：
- 文献未解释 → 如实说「未找到」
- 内置库没有 → 如实说，不编造
- 不主动联网查

---

## G.18 新建项目

**用户动作**：
用户写论文，新建项目，把相关文献托进去。

**系统响应**：
- 新建项目，命名
- 从总库托文献进项目
- 项目内有独立问答、笔记、知识库、综述
- 项目对话默认限定项目内
- 移除文献 ≠ 删除，总库还在

**涉及模块**：专题 / 项目、文献拖拽、知识库、笔记与划线、工作台与页面

**产出**：项目元数据 + 项目内文献 / 笔记 / 知识 / 综述

**断点检查**：
- 移除文献 → 总库保留
- 项目问答范围 → 默认限定项目内
- 删除项目 → 文献保留

---

## G.19 切换用户

**用户动作**：
同一台机器上，另一个用户想用自己的数据。

**系统响应**：
- 设置里切换用户
- 当前 `data/` 目录切换到目标用户目录
- 工作台、阅读页、笔记、知识库全部刷新
- 切换中不丢数据
- 切换失败报错，保持当前用户不变

**涉及模块**：设置页与用户体系、工作台与页面

**产出**：用户切换 + 数据隔离

**断点检查**：
- 切换中 → 不丢数据，当前用户数据已落盘
- 切换失败 → 报错，保持当前用户不变
- 不做真登录、不做密码

---

## G.20 设置

**用户动作**：
用户想配置 API、主题、导出数据。

**系统响应**：
- 设置页分五组：用户 / API / 界面 / 数据 / 关于
- 用户：当前用户、切换、新建、删除
- API：provider / key / model / 预算 / 用量
- 界面：主题 / 语言
- 数据：导出 / 备份 / 清除
- 关于：版本 / 更新日志 / 技术栈

**涉及模块**：设置页与用户体系、工作台与页面

**产出**：配置更新

**断点检查**：
- 删除用户 → 二次确认
- API 配置 → key 从环境变量读，不落明文
- 清除数据 → 用户显式发起
