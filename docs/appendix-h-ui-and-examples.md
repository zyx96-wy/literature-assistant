## H.3 查词弹窗

**触发**：选中文字，含模型名 / 术语才显示。
```
选中文字
↓
浮动条：[🖍 划线] [❓ 查词]
↓
查词弹窗
↓
模型卡片 / 术语卡片
```

**弹窗内容**：
```
┌─────────────────────────────────────┐
│ ❓ 查词 │
├─────────────────────────────────────┤
│ 选中内容：「BERT」 │
│ 类型：模型 │
│ │
│ ┌─────────────────────────────┐ │
│ │ 模型卡片 │ │
│ │ BERT │ │
│ │ 类型：预训练语言模型 │ │
│ │ 出处：lit_003 ¶5 │ │
│ │ 核心思想：双向 Transformer │ │
│ │ 相关文献：lit_003, lit_007 │ │
│ └─────────────────────────────┘ │
│ │
│ [📌 收藏为知识] [↪ 跳到原文] [关闭] │
└─────────────────────────────────────┘
```

**只做模型 / 术语查询，不做通用问答。**
